# Treasure of the Turkic Lands - Kashgari Quest

An interactive map application that overlays the historical Mahmud Kashgari map (1072 CE) over modern maps for a detective quest experience.

## Features

- **Multiple Map Providers**: Switch between OpenStreetMap, OpenTopoMap, CartoDB Voyager, and CartoDB Dark Matter
- **Kashgari Map Overlay**: Toggle the historical Turkic world map overlay with adjustable opacity
- **Default Locations**: Quick navigation to Tokmok and Barskoon in Kyrgyzstan
- **Interactive Markers**: Click on map to get coordinates for your treasure hunt
- **Detective Quest Theme**: Styled interface for searching ancient Silk Road treasures

## Locations

- **Tokmok** (42.8424°N, 75.2988°E): Ancient Suyab - Capital of the Western Turkic Khaganate
- **Barskoon** (42.1344°N, 77.5725°E): Birthplace of Mahmud Kashgari, the great Turkic scholar

## Usage

Visit the GitHub Pages site to explore the map and search for clues to ancient treasures along the Silk Road.

## About the Kashgari Map

The Mahmud Kashgari map is from "Diwan Lughat al-Turk" (1072 CE), one of the earliest maps of the Turkic world, showing Central Asia with the world centered on Balasagun (near modern Tokmok).
